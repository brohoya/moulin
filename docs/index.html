moulin à paroles [mulɛ̃ a paʀɔl]: a person who talks all the time.

Caution: Moulin is not affiliated with OpenAI and it automates the ChatGPT web app. The OpenAI Terms of Use forbid this, so OpenAI can warn or suspend the account.
